# Генератор сертификатов и бейджей SmileClinic

**Боевой адрес:** https://mihatal.github.io/smileclinic/certificate/ — корень репо и /sertificate/ редиректят сюда. Репозиторий `mihatal/smileclinic` (публичный, GitHub Pages из ветки `main`).

Однофайловый веб-инструмент с двумя документами (переключатель вверху панели):
**Сертификаты** — имя, номер, номинал → PDF/PNG поверх фирменного макета;
**Бейджи** — имя и должность сотрудника поверх макета бейджа, по одному, пакетом или сеткой на листе A4.

**Файл:** `index.html` — самодостаточный, 1,9 МБ (в репозитории лежит как `certificate/index.html`). Внутри уже лежат pdf-lib, fontkit, шрифты и сам макет-шаблон. Ни одного внешнего запроса: работает и с двойного клика с диска, и на GitHub Pages.

## Что умеет

- Живой предпросмотр 1:1 с макетом.
- PDF с **живым текстом** (не картинка): выделяется, ищется, печатается без пикселей.
- PNG 2160×3200 — отправить в мессенджер.
- Пакетный режим: список `имя; номер; номинал` построчно → один PDF, каждый сертификат отдельной страницей.
- Кнопка «Следующий номер» + опция автоувеличения номера после скачивания.
- Срок действия: кнопки +3 мес / +6 мес / +1 год или своя дата, либо строка убирается совсем.
- Подвал (режим работы, призыв, телефон) и текст сертификата редактируются и сохраняются в браузере.
- Слишком длинный текст переносится сам и ужимается по кеглю, чтобы не наехать на блок с номером.
- Можно подключить свой шрифт (.ttf/.otf) — файл остаётся в браузере. Символы, которых в нём нет (например ₽ в Gotham Pro), берутся из встроенного шрифта.

## Что умеет вкладка «Бейджи»

- Имя и должность на макете бейджа 1034×542 pt, живой предпросмотр 1:1.
- ПРОПИСНЫМИ по умолчанию, как на макете; регистр выключается галкой.
- Длинное имя само ужимается по кеглю, совсем длинное переносится на две строки вверх — до должности не достаёт. Должность так же ужимается и центрируется относительно своей базовой линии.
- Пакетный режим: список `имя; должность` построчно, вставляется прямо из таблицы.
- **Лист A4** — сетка бейджей с метками реза. Ширина бейджа в мм (по умолчанию 90 → высота 47,2 мм по пропорции макета) и зазор. Подсказка сразу считает вместимость листа (при 90 мм и зазоре 4 мм — 2×5 = 10 шт.). Неполный лист центрируется по факту, а не прижимается к верху.
- PNG 2068×1084 — отправить в мессенджер.

**Шрифт бейджа — Gotham Pro Medium**, вшит в сборку (`src/G-Med.otf`, урезан до кириллицы и латиницы, 23 КБ). Опознан по макету измерением: совпадение по глифам до 2 px, IoU 0,92 — против 0,70 у лучшего бесплатного заменителя (Montserrat SemiBold) и 0,49 у Jost. Выбора шрифта на вкладке бейджей нет, печать совпадает с макетом один в один.

⚠️ Gotham Pro — платная гарнитура, а репозиторий публичный: вшитый файл доступен всем, у кого есть адрес инструмента. Решение Миши от 27.08.2026.

**Грабля pdf-lib с OTF.** Gotham — OTF (CFF). При `embedFont(..., {subset:true})` pdf-lib ломает кодировку: в PDF вместо кириллицы печатаются `! " # $ %`. Лечится `subset:false` — шрифт вшивается целиком (те же 23 КБ). У TTF-шрифтов сертификата сабсет работает нормально, поэтому флаг зависит от документа.

## Обновить опубликованную версию

Репозиторий склонирован не в vault — правки катятся так:

```bash
git clone https://github.com/mihatal/smileclinic.git && cd smileclinic
# заменить certificate/index.html свежей сборкой из src/build.py
git commit -am "правка" && git push
```
Pages пересобираются сами за минуту. Достаточно одного `certificate/index.html`, папка `src/` лежит там только ради пересборки.

**Репозиторий публичный** — иначе Pages не работают на бесплатном плане. Значит макет сертификата открыт: любой, кто знает адрес, может выпустить себе «сертификат SmileClinic». Защита от этого не техническая, а учётная — номера сертификатов и их выдача должны сверяться в клинике.

## Пересборка (если правится макет или вёрстка инструмента)

В `src/` лежат исходники:

| Файл | Что это |
|---|---|
| `tool.tpl.html` | шаблон инструмента с плейсхолдерами `{{...}}` — правится здесь |
| `build.py` | вшивает библиотеки, шрифты и макет в один `index.html`, по умолчанию собирает в `certificate/` |
| `make_template.py` | из нового пустого макета делает `template_clean.pdf` и `bg2x.png` |
| `calibrate.py` | построчно сверяет выданный сертификат с эталоном и называет константу-виновника |
| `badge_calibrate.py` | то же для бейджа: Δширины, Δверха, Δцентра по двум строкам |
| `badge_template.pdf` | макет бейджа без текста, из него печатается PDF |
| `badge_bg2x.png` | фон предпросмотра бейджа, 2068×1084 |
| `badge_reference.pdf`, `badge_reference.png` | эталон от дизайнера (Юлия Момот / Медсестра ЦСО) |
| `G-Med.otf` | Gotham Pro Medium, урезанный до кириллицы и латиницы — шрифт бейджа |
| `test-badge.mjs` | прогон вкладки бейджей: предпросмотр, PDF, лист A4, пакет, длинные строки, возврат к сертификату |
| `template_clean.pdf` | пустой макет, из которого удалён текст в редактируемой зоне |
| `bg2x.png` | фон для предпросмотра, 2160×3200 |
| `M-Reg.ttf`, `M-Bold.ttf` | Montserrat 400/700, урезанный до кириллицы и латиницы (OFL) |
| `test*.mjs` | прогон в Playwright: скачивание PDF/PNG, пакет, длинный текст, свой шрифт, юзабилити, боевой адрес |

```bash
cd src
curl -L -o pdf-lib.min.js https://unpkg.com/pdf-lib@1.17.1/dist/pdf-lib.min.js
curl -L -o fontkit.umd.min.js https://unpkg.com/@pdf-lib/fontkit@1.1.1/dist/fontkit.umd.min.js
python3 build.py ../certificate/index.html
```

**Починка бейджа.** Введи в инструменте «Юлия Момот» / «Медсестра ЦСО», скачай PDF и сравни с эталоном:

```bash
python3 src/badge_calibrate.py src/badge_reference.pdf ~/Downloads/"Бейдж Юлия Момот.pdf"
```

Δширины лечится кеглем или трекингом, Δверха — базовой линией, Δцентра — центрированием. Дизайнер прислал новый макет бейджа — положи его PDF без текста как `src/badge_template.pdf`, PNG 2× как `src/badge_bg2x.png`, пересобери и прогони `badge_calibrate.py`.

## Карта раскладки бейджа

Страница 1034×542 pt, отсчёт сверху, `y` — базовая линия. Всё в объекте `L_BADGE`.

| Что | Константа | Значение |
|---|---|---|
| имя | `L_BADGE.name` | кегль 51,5 (капитель 36,5), базовая линия 282, ширина до 880 pt, ужимается до 30 |
| должность | `L_BADGE.role` | кегль 29,5 (капитель 21), базовая линия 341, ужимается до 18 |
| трекинг | `track` | 0,4 у имени, 0,25 у должности |
| центр | `L_BADGE.CX` | 517 |
| граница золота | `L_BADGE.darkBottom` | 389 — ниже печатать нельзя |

Макет бейджа заливать не надо: `badge_template.pdf` от дизайнера уже без текста, инструмент печатает поверх.

**На листе A4 подложка рисуется своими прямоугольниками**, а не макетом дизайнера: pdf-lib при `embedPage` теряет прозрачность фигмовской формы, и от бейджа остаётся одна рамка. Цвета вынесены в `L_BADGE.paper` (фон `rgb(26,26,24)`, золото `rgb(127,113,71)`, граница золота 389, рамка 1 pt чёрная) — если дизайнер поменяет макет, править и их тоже.

## Как это устроено внутри

Инструмент не рисует сертификат с нуля: он берёт настоящий PDF-макет, закрашивает середину (`y` 520–1425 pt, фон там ровный `#1C1C1A`) и печатает текст поверх. Шапка, заголовок «СЕРТИФИКАТ», золотые линии и подвал с сайтом остаются исходными векторами.

Раскладка выверена по эталонному сертификату N005 попиксельно: кегли 40/41/25 pt, базовые линии 616–790 / 927,75 / 985,75 / 1119,5 / 1206,75 / 1242,25 / 1306,75 / 1341,75 / 1376,75, межстрочный 58 pt. Расхождение с эталоном — до 2,5 pt по ширине строки и до 0,5 pt по вертикали.

**Шрифт:** макет свёрстан **Montserrat** (400 и 700), а не Gotham Pro. Проверено метрикой (совпадение ширин 8 строк с ошибкой 0,38 %) и попиксельным сравнением (IoU 0,70 против 0,54 у лучшего варианта Gotham). Поэтому встроен Montserrat — иначе новый текст не совпал бы со старым в том же файле. Если нужен фирменный Gotham Pro, он подключается через «Свой шрифт»: шрифт платный, в открытый репозиторий его класть нельзя.

## Карта раскладки

Всё, что печатается, задано объектом `L` в начале скрипта `src/tool.tpl.html`. Координаты — пункты страницы 1080×1600, отсчёт сверху; `y` у текста это базовая линия, а не верх букв.

| Что | Константа | Значение |
|---|---|---|
| зона заливки | `L.cover` | 520–1425 pt, цвет `L.bg` = rgb(28,28,26) |
| текст сертификата | `L.body` | кегль 40, межстрочный 58, трекинг −0,2, блок центрируется по `centerY` 703, ширина строки до 900 pt, ужимается до кегля 26 |
| номер / номинал | `L.accent` | кегль 41 жирный, трекинг +0,5, базовые линии 927,75 и 985,75; если строка одна — 956,75 |
| срок действия | `L.srok` | кегль 25, базовая линия 1119,5 |
| разделитель | `L.divider` | линия x 182–896, y 1150, толщина 1 pt, белая |
| режим работы | `L.hours` | кегль 25, базовые линии 1206,75 и 1242,25 |
| призыв | `L.cta` | кегль 25, базовые линии 1306,75 и 1341,75 |
| телефон | `L.phone` | кегль 25 жирный, базовая линия 1376,75 |

Разделитель приходится рисовать заново: он попадает под заливку.

## Починка

**Что-то поехало по месту.** Введи в инструменте эталонный набор (Сергей, N005, 5000, срок 01.12.2026, часы до 22:00), скачай PDF и сравни с эталоном:

```bash
python3 src/calibrate.py "Сертификат SmileClinic.pdf" ~/Downloads/"Сертификат N005 Сергей.pdf"
```

Скрипт печатает по строкам Δширины и Δверха и сразу называет константу, которая за строку отвечает. Δверха лечится сдвигом базовой линии, Δширины — кеглем или трекингом. Допуск: ±4 pt по ширине, ±0,6 pt по вертикали.

**Клиника прислала новый макет.** Нужен именно пустой макет в PDF, 1080×1600 pt:

```bash
python3 src/make_template.py "Сертификат пустой.pdf"   # → template_clean.pdf + bg2x.png
python3 src/build.py ../certificate/index.html
```

`make_template.py` проверит размер страницы, замерит однородность фона в зоне заливки (было 98,8 % — если сильно меньше, фон там не ровный и прямоугольник станет заметен) и вырежет текст. После этого прогони `calibrate.py`: если макет подвинули, координаты в `L` придётся пересчитать.

**Проверка перед выкладкой:** `node src/test.mjs` (PDF, PNG, пакет), `test2.mjs` (длинный текст, отсутствующий номинал, свой шрифт), `test3.mjs` (юзабилити: кликабельность подписей, переносы, вкладки, сохранение настроек), `test-live.mjs` (боевой адрес). Нужен `npm i playwright`.

## Грабли, на которые уже наступили

- **Скрытый текст под заливкой.** Заливка перекрывает текст макета визуально, но он остаётся в файле и копируется. Из-за этого в PDF сидело «с 9:00 до 21:00», хотя на макете было 22:00. Лечится только вырезанием — `make_template.py`.
- **Своё письмо у чужого шрифта.** В Gotham Pro нет ₽ — вместо него печатался пустой квадрат. Инструмент режет строку на куски и недостающие символы берёт из встроенного Montserrat (`segs()` в скрипте).
- **Трекинг в PDF.** `pdf-lib` не умеет межбуквенный интервал в `drawText`; он ставится оператором `setCharacterSpacing` до вызова и сбрасывается после, а центрирование считает ширину сама (`ширина строки + трекинг × (символов − 1)`).
- **Кернинг у canvas и pdf-lib разный.** Предпросмотр меряет строки через `measureText`, PDF — через `widthOfTextAtSize`. Расхождение доли процента, поэтому переносы считаются по canvas, а центрирование — каждым движком по себе.
- **Оригинал центрирован неточно.** В эталонном сертификате часть строк сдвинута влево на полпробела — в исходнике висячие пробелы в конце строк. Инструмент центрирует честно, поэтому в `calibrate.py` небольшая Δ по горизонтали — норма, а не ошибка.
