# Генератор сертификатов SmileClinic

Однофайловый веб-инструмент: вводишь имя, номер и номинал — скачиваешь готовый PDF или PNG на фирменном макете клиники.

**Открыть:** https://mihatal.github.io/smileclinic/certificate/

Старые адреса — корень репозитория и `/sertificate/` (написание с ошибкой) — редиректят сюда же.

Весь инструмент — один `certificate/index.html` (1,8 МБ). Внутри уже лежат pdf-lib, fontkit, шрифты и векторный макет, внешних запросов ноль: работает и на GitHub Pages, и с двойного клика по файлу с диска, и без интернета.

## Что умеет

- Живой предпросмотр 1:1 с макетом.
- PDF с настоящим текстом, а не картинкой: выделяется, ищется, печатается без пикселей.
- PNG 2160×3200 — отправить в мессенджер.
- Пакетный режим: список `имя; номер; номинал` построчно (можно вставить прямо из таблицы, табуляция тоже разделитель) → один PDF, каждый сертификат отдельной страницей. 50 штук собираются меньше чем за секунду.
- «Следующий номер» и опция автоувеличения после скачивания.
- Срок действия: кнопки +3 мес / +6 мес / +1 год, своя дата или строка целиком убирается.
- Текст сертификата и подвал (режим работы, призыв, телефон) редактируются и сохраняются в браузере.
- Длинный текст переносится сам и ужимается по кеглю, чтобы не наехать на блок с номером; слово без пробелов рвётся по буквам.
- Можно подключить свой шрифт (.ttf/.otf). Символы, которых в нём нет — например ₽ в Gotham Pro — берутся из встроенного.

## Как устроено

Инструмент не рисует сертификат с нуля: он берёт настоящий PDF-макет, закрашивает середину (`y` 520–1425 pt, фон там ровный `#1C1C1A`) и печатает текст поверх. Шапка с логотипом, заголовок «СЕРТИФИКАТ», золотые линии и подвал с адресом сайта остаются исходными векторами.

Раскладка выверена по эталонному сертификату попиксельно: кегли 40/41/25 pt, межстрочный 58 pt, базовые линии 616–790 / 927,75 / 985,75 / 1119,5 / 1206,75 / 1242,25 / 1306,75 / 1341,75 / 1376,75. Расхождение с эталоном — до 2,5 pt по ширине строки и до 0,5 pt по вертикали.

Из шаблона удалён текст в редактируемой зоне, иначе он оставался бы под заливкой невидимым, но копируемым.

**Шрифт:** макет свёрстан Montserrat 400/700 — это подтверждают и метрики (совпадение ширин восьми строк с ошибкой 0,38 %), и попиксельное сравнение (IoU 0,70 против 0,54 у ближайшего Gotham Pro). Поэтому встроен Montserrat, урезанный до кириллицы и латиницы, лицензия OFL — файл `OFL.txt`. Фирменный Gotham Pro подключается через «Свой шрифт»: он платный, в открытый репозиторий его класть нельзя, файл остаётся в браузере.

## Пересборка

```bash
cd src
curl -L -o pdf-lib.min.js https://unpkg.com/pdf-lib@1.17.1/dist/pdf-lib.min.js
curl -L -o fontkit.umd.min.js https://unpkg.com/@pdf-lib/fontkit@1.1.1/dist/fontkit.umd.min.js
python3 build.py ../certificate/index.html
```

Правится `src/tool.tpl.html`, `build.py` вшивает в него библиотеки, шрифты и макет. Проверка — `node src/test.mjs`, `test2.mjs` (длинный текст, свой шрифт), `test3.mjs` (юзабилити) — нужен `npm i playwright`.

## Карта раскладки

Всё, что печатается, задано объектом `L` в начале скрипта `src/tool.tpl.html`. Координаты — пункты страницы 1080×1600, отсчёт сверху; `y` у текста это базовая линия, а не верх букв.

| Что | Константа | Значение |
|---|---|---|
| зона заливки | `L.cover` | 520–1425 pt, цвет `L.bg` = rgb(28,28,26) |
| текст сертификата | `L.body` | кегль 40, межстрочный 58, трекинг −0,2, блок центрируется по `centerY` 703, ширина строки до 900 pt, ужимается до кегля 26 |
| номер / номинал | `L.accent` | кегль 41 жирный, трекинг +0,5, базовые линии 927,75 и 985,75; если строка одна — 956,75 |
| срок действия | `L.srok` | кегль 25, базовая линия 1119,5 |
| разделитель | `L.divider` | линия x 182–896, y 1150, толщина 1 pt, белая |
| режим работы | `L.hours` | кегль 25, базовые линии 1206,75 и 1242,25 |
| призыв | `L.cta` | кегль 25, базовые линии 1306,75 и 1341,75 |
| телефон | `L.phone` | кегль 25 жирный, базовая линия 1376,75 |

Разделитель приходится рисовать заново: он попадает под заливку.

## Починка

**Что-то поехало по месту.** Введи в инструменте эталонный набор (Сергей, N005, 5000, срок 01.12.2026, часы до 22:00), скачай PDF и сравни с эталоном:

```bash
python3 src/calibrate.py "Сертификат SmileClinic.pdf" ~/Downloads/"Сертификат N005 Сергей.pdf"
```

Скрипт печатает по строкам Δширины и Δверха и сразу называет константу, которая за строку отвечает. Δверха лечится сдвигом базовой линии, Δширины — кеглем или трекингом. Допуск: ±4 pt по ширине, ±0,6 pt по вертикали.

**Клиника прислала новый макет.** Нужен именно пустой макет в PDF, 1080×1600 pt:

```bash
python3 src/make_template.py "Сертификат пустой.pdf"   # → template_clean.pdf + bg2x.png
python3 src/build.py ../certificate/index.html
```

`make_template.py` проверит размер страницы, замерит однородность фона в зоне заливки (было 98,8 % — если сильно меньше, фон там не ровный и прямоугольник станет заметен) и вырежет текст. После этого прогони `calibrate.py`: если макет подвинули, координаты в `L` придётся пересчитать.

**Проверка перед выкладкой:** `node src/test.mjs` (PDF, PNG, пакет), `test2.mjs` (длинный текст, отсутствующий номинал, свой шрифт), `test3.mjs` (юзабилити: кликабельность подписей, переносы, вкладки, сохранение настроек), `test-live.mjs` (боевой адрес). Нужен `npm i playwright`.

## Грабли, на которые уже наступили

- **Скрытый текст под заливкой.** Заливка перекрывает текст макета визуально, но он остаётся в файле и копируется. Из-за этого в PDF сидело «с 9:00 до 21:00», хотя на макете было 22:00. Лечится только вырезанием — `make_template.py`.
- **Своё письмо у чужого шрифта.** В Gotham Pro нет ₽ — вместо него печатался пустой квадрат. Инструмент режет строку на куски и недостающие символы берёт из встроенного Montserrat (`segs()` в скрипте).
- **Трекинг в PDF.** `pdf-lib` не умеет межбуквенный интервал в `drawText`; он ставится оператором `setCharacterSpacing` до вызова и сбрасывается после, а центрирование считает ширину сама (`ширина строки + трекинг × (символов − 1)`).
- **Кернинг у canvas и pdf-lib разный.** Предпросмотр меряет строки через `measureText`, PDF — через `widthOfTextAtSize`. Расхождение доли процента, поэтому переносы считаются по canvas, а центрирование — каждым движком по себе.
- **Оригинал центрирован неточно.** В эталонном сертификате часть строк сдвинута влево на полпробела — в исходнике висячие пробелы в конце строк. Инструмент центрирует честно, поэтому в `calibrate.py` небольшая Δ по горизонтали — норма, а не ошибка.
